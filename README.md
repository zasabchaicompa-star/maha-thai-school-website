# เว็บไซต์เยี่ยมชมโรงเรียนมหาไถ่ศึกษาเลย

เว็บไซต์ต้นแบบสำหรับการเยี่ยมชมโรงเรียนผ่านหน้าเว็บ รองรับมือถือและคอมพิวเตอร์

## ไฟล์หลัก
- `index.html` — หน้าเว็บไซต์
- `styles.css` — รูปแบบและ responsive layout
- `script.js` — เมนูและการเลือกอาคารบนแผนที่จำลอง
- `assets/` — โลโก้ ภาพอาคาร และ favicon

## เผยแพร่ด้วย Netlify
1. เข้า Netlify แล้วเลือก **Add new site → Import an existing project**.
2. เลือก GitHub และอนุญาตให้ Netlify เข้าถึง repository นี้
3. เลือก `zasabchaicompa-star/maha-thai-school-website`
4. Build command เว้นว่าง และ Publish directory ใส่ `.`
5. กด Deploy site

เมื่อเชื่อมสำเร็จ Netlify จะติดตาม branch `main` และสร้าง deployment ใหม่เมื่อมี commit ใหม่

## หมายเหตุ
- แผนที่ 3D เป็นภาพจำลองแนวคิด ไม่ใช่ผังอาคารจริง
- ภาพอาคารเซนต์เมรี่เป็นภาพที่ผู้จัดทำส่งมา
- ควรตรวจสอบรายละเอียด ที่อยู่ เบอร์โทรศัพท์ และสิทธิ์การเผยแพร่ภาพกับโรงเรียนก่อนใช้งานจริง
- เว็บไซต์นี้เป็นเว็บไซต์ต้นแบบ ไม่ได้อ้างว่าเป็นเว็บไซต์ทางการของโรงเรียน
